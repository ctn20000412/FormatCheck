## 项目概述

项目目标是实现一套“开发文档规范检查”系统，支持：

1. 规则准备支持两种方式：
   - 上传规范文档，通过规则抽取 Agent 提取排版和格式要求，生成中间文件 `规范.js`
   - 直接上传符合规范的 `完整规范.js`，跳过抽取和人工确认
2. 对抽取得到的 `规范.js` 在前端以可读、可编辑形式展示，用户确认后生成 `完整规范.js`
3. 上传待检查文档，通过格式检查 Agent 基于 `完整规范.js` 输出检查报告，并在文档内生成批注版本

## Agent 输入约定

- 规则抽取 Agent 输入为：提示词 + 上传的规范文件
- 格式检查 Agent 输入为：提示词 + 待检查文件 + `完整规范.js`
- Agent 接收的是原始文件，不要求 Java 后端先将文件解析为纯文本内容后再传入

## 技术约束

- 后端：Java 23、Spring Boot、MyBatis-Plus
- Agent/LLM 交互：Python 3.10
- 前端：Vue
- 数据存储：当前版本不使用数据库，采用文件系统保存会话与产物
