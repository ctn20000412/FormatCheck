# 测试用例文档

## 1. 测试范围

覆盖以下范围：

- 规范文档上传
- 完整规则文件直传
- 规则抽取
- 规则展示与确认
- 待检查文档上传
- 格式检查
- 报告生成
- 批注文档生成
- 异常与边界场景

## 2. 测试环境建议

- 前端：Vue 3
- 后端：Spring Boot 3.x / Java 23
- Agent 服务：Python 3.10 / FastAPI
- 文件存储目录：本地 `storage/sessions`
- LLM：测试环境可配置 mock 响应与真实响应两套模式

## 8. 验收重点

- `规范.js` 与 `完整规范.js` 生命周期符合设计
- 直接上传的 `完整规范.js` 校验通过后可直接用于检查
- 检查报告字段完整
- 批注文档与问题列表位置一致
- 失败场景有明确错误提示，不出现静默失败
