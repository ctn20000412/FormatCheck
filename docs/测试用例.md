# 测试用例

## 1. 正常流程

| 编号 | 场景 | 输入 | 期望 |
| --- | --- | --- | --- |
| T001 | DOCX 规范 + DOCX 论文 | `standard.docx`、`checked_file.docx` | 生成 `format_rule.json`、统计分析文档、批注版论文 |
| T002 | PDF 规范 + DOCX 论文 | `standard.pdf`、`checked_file.docx` | 能抽取规则并生成两个结果文件 |
| T003 | Markdown 规范 + DOCX 论文 | `standard.md`、`checked_file.docx` | 能抽取规则并检查论文 |

## 3. 文件校验

| 编号 | 场景 | 期望 |
| --- | --- | --- |
| T201 | 未上传规范文件 | 前端禁止提交 |
| T202 | 未上传待检论文 | 前端禁止提交 |

## 4. Agent1 规则抽取

| 编号 | 场景 | 期望 |
| --- | --- | --- |
| T301 | LLM 返回合法 JSON | 保存 `format_rule.json` |
| T302 | LLM 返回 Markdown 包裹 JSON | 脚本能提取并保存 JSON |
| T303 | LLM 返回非法 JSON | 停止流程，提示重试 |
| T304 | `rules` 为空 | 停止进入 Agent2 |

## 5. Agent2 格式检查

| 编号 | 场景 | 期望 |
| --- | --- | --- |
| T401 | 检查发现多类错误 | 统计数据按类别和严重程度聚合 |
| T402 | 检查无错误 | `issues` 为空，前端展示 0 个错误 |
| T403 | LLM 输出缺少必要字段 | 停止文档生成并提示结构错误 |
| T404 | 部分错误缺少锚文本 | 报告保留错误，批注版记录未定位 issue |

## 6. 文档生成

| 编号 | 场景 | 期望 |
| --- | --- | --- |
| T501 | 生成统计分析文档 | 文件存在且包含统计概览和错误明细 |
| T502 | 生成批注版论文 | 文件存在且包含 Word comments |
| T503 | 原始论文文件 | 不被修改 |
| T504 | 结果文件下载 | 前端下载链接可访问 |

## 7. 回归检查

每次修改 prompt、skill 或脚本后至少执行：

1. 一个正常 DOCX 全流程样例。
2. 一个 LLM 非法 JSON 样例。
3. 一个无错误样例。
4. 一个批注锚文本未命中样例。
