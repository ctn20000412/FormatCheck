# 业务流程图 / 用户流程图

## 1. 业务总流程

```mermaid
flowchart TD
    A[开始] --> B{规则准备方式}
    B -->|规范文档抽取| C[上传规范文档]
    C --> D[规则抽取 Agent 提取规则]
    D --> E[生成 规范.js]
    E --> F[前端展示规则]
    F --> G{用户是否修改}
    G -- 是 --> H[编辑并保存规则]
    G -- 否 --> I[直接确认规则]
    H --> J[生成 完整规范.js]
    I --> J
    J --> K[删除 规范.js]
    B -->|直接上传规则文件| L[上传 完整规范.js]
    L --> M[校验规则结构]
    M --> N[保存 完整规范.js]
    K --> O[上传待检查文档]
    N --> O
    O --> P[格式检查 Agent 执行检查]
    P --> Q[输出检查报告]
    Q --> R[生成带批注文档]
    R --> S[保存产物到会话目录]
    S --> T[结束]
```

## 3. 规则抽取业务流程

```mermaid
flowchart LR
    A[用户上传规范文件] --> B[后端校验文件格式]
```

## 7. 任务状态流转图

```mermaid
stateDiagram-v2
    [*] --> CREATED
    CREATED --> UPLOADED
    UPLOADED --> PROCESSING
    PROCESSING --> WAITING_CONFIRM: 规则抽取完成
    WAITING_CONFIRM --> CONFIRMED: 用户确认规则
    UPLOADED --> CONFIRMED: 规则直传校验通过
    PROCESSING --> COMPLETED: 检查任务完成
    CREATED --> FAILED
    UPLOADED --> FAILED
    PROCESSING --> FAILED
    WAITING_CONFIRM --> FAILED
```

## 8. 关键页面流程说明

### 7.1 规范抽取页

- 用户上传规范文档
- 系统返回任务编号和抽取状态
- 抽取完成后跳转到规则确认页

### 7.2 规则直传页

- 用户上传 `完整规范.js`
- 系统执行规则结构校验
- 校验通过后可直接用于格式检查

### 7.3 规则确认页

- 以分类表单或树形结构展示抽取结果
- 支持新增、删除、修改规则项
- 点击确认后生成 `完整规范.js`

### 7.4 格式检查页

- 用户上传待检文档
- 选择已确认规则会话，规则可来自抽取模式或直传模式
- 提交后进入结果等待状态

### 7.5 结果页

- 展示问题摘要
- 展示问题清单
- 下载报告
- 下载带批注文档
