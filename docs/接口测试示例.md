# 接口测试示例

以下示例采用 `curl` 风格，接口基地址假设为：

`http://localhost:8080/api`

Python Agent 服务基地址假设为：

`http://localhost:9000`

## 1. 创建规则抽取会话

```bash
curl -X POST "http://localhost:8080/api/sessions" \
  -H "Content-Type: application/json" \
  -d '{
    "type": "RULE_EXTRACTION",
    "name": "研发文档规范抽取"
  }'
```

示例响应：

```json
{
  "code": 0,
  "message": "success",
  "data": {
    "sessionId": "sess_rule_001",
    "type": "RULE_EXTRACTION",
    "status": "CREATED",
    "createdAt": "2026-04-21T10:00:00+08:00"
  }
}
```

## 2. 上传规范文档

```bash
curl -X POST "http://localhost:8080/api/sessions/sess_rule_001/files/standard" \
  -H "Content-Type: multipart/form-data" \
  -F "file=@E:/samples/文档编写规范.docx"
```

## 3. 发起规则抽取

```bash
curl -X POST "http://localhost:8080/api/rules/extract" \
  -H "Content-Type: application/json" \
  -d '{
    "sessionId": "sess_rule_001",
    "schemaVersion": "1.0"
  }'
```

## 4. 获取抽取后的规则

```bash
curl "http://localhost:8080/api/rules/sess_rule_001"
```

## 5. 确认最终规则

```bash
curl -X POST "http://localhost:8080/api/rules/sess_rule_001/confirm" \
  -H "Content-Type: application/json" \
  -d '{
    "sessionId": "sess_rule_001",
    "versionNote": "人工确认一级标题规则",
    "ruleContent": [
      {
        "rule_id": "R001",
        "category": "格式规范",
        "scope": "一级标题",
        "rule_name": "一级标题字体字号要求",
        "description": "一级标题应使用黑体三号，居中，段前后间距符合规范",
        "check_type": "hybrid",
        "check_object": ["font_family", "font_size", "alignment", "spacing_before", "spacing_after"],
        "expected": {
          "font_family": "黑体",
          "font_size": "三号",
          "alignment": "center"
        },
        "severity": "high",
        "source_text": "规范原文中的对应条款",
        "applicable_sections": ["title_level_1"],
        "user_confirmed": true
      }
    ]
  }'
```

## 6. 创建格式检查会话

```bash
curl -X POST "http://localhost:8080/api/sessions" \
  -H "Content-Type: application/json" \
  -d '{
    "type": "FORMAT_CHECK",
    "name": "方案文档格式检查"
  }'
```

## 7. 创建规则直传会话

```bash
curl -X POST "http://localhost:8080/api/sessions" \
  -H "Content-Type: application/json" \
  -d '{
    "type": "RULE_IMPORT",
    "name": "导入现成规则文件"
  }'
```

## 8. 直接上传完整规范.js

```bash
curl -X POST "http://localhost:8080/api/sessions/sess_rule_import_001/files/rule-final" \
  -H "Content-Type: multipart/form-data" \
  -F "file=@E:/samples/完整规范.js"
```

示例响应：

```json
{
  "code": 0,
  "message": "success",
  "data": {
    "sessionId": "sess_rule_import_001",
    "finalRuleFileName": "完整规范.js",
    "validated": true,
    "status": "CONFIRMED"
  }
}
```

## 9. 上传待检查文档

```bash
curl -X POST "http://localhost:8080/api/sessions/sess_check_001/files/target" \
  -H "Content-Type: multipart/form-data" \
  -F "file=@E:/samples/系统设计说明.docx"
```

## 10. 发起格式检查

```bash
curl -X POST "http://localhost:8080/api/checks" \
  -H "Content-Type: application/json" \
  -d '{
    "sessionId": "sess_check_001",
    "ruleSessionId": "sess_rule_001",
    "checkLevel": "NORMAL"
  }'
```

使用直传规则文件时，请将 `ruleSessionId` 替换为规则直传会话，例如 `sess_rule_import_001`。

规则文件内容示例：

```javascript
module.exports = [
  {
    rule_id: "R001",
    category: "格式规范",
    scope: "一级标题",
    rule_name: "一级标题字体字号要求",
    description: "一级标题应使用黑体三号，居中，段前后间距符合规范",
    check_type: "hybrid",
    check_object: ["font_family", "font_size", "alignment", "spacing_before", "spacing_after"],
    expected: {
      font_family: "黑体",
      font_size: "三号",
      alignment: "center"
    },
    severity: "high",
    source_text: "规范原文中的对应条款",
    applicable_sections: ["title_level_1"],
    user_confirmed: true
  }
];
```

```bash
curl -OJ "http://localhost:8080/api/files/download?sessionId=sess_check_001&fileType=REPORT_MD"
```

```bash
curl -OJ "http://localhost:8080/api/files/download?sessionId=sess_check_001&fileType=ANNOTATED_DOC"
```

## 14. Java 调 Python 规则抽取 Agent 示例

```bash
curl -X POST "http://localhost:9000/internal/agent/rules/extract" \
  -H "Content-Type: application/json" \
  -d '{
    "sessionId": "sess_rule_001",
    "filePath": "E:/app/storage/sessions/sess_rule_001/source/文档编写规范.docx",
    "outputDir": "E:/app/storage/sessions/sess_rule_001/rules",
    "promptText": "你是规则抽取 Agent。请基于上传的规范文件提取文档排版、格式、标题层级、编号、图表要求，并按约定 schema 输出。",
    "schemaVersion": "1.0"
  }'
```

## 15. Java 调 Python 格式检查 Agent 示例

```bash
curl -X POST "http://localhost:9000/internal/agent/checks/execute" \
  -H "Content-Type: application/json" \
  -d '{
    "sessionId": "sess_check_001",
    "targetFilePath": "E:/app/storage/sessions/sess_check_001/source/系统设计说明.docx",
    "ruleFilePath": "E:/app/storage/sessions/sess_rule_001/rules/完整规范.js",
    "outputDir": "E:/app/storage/sessions/sess_check_001/output",
    "promptText": "你是格式检查 Agent。请依据完整规范.js 检查待检文件的排版和格式问题，输出错误位置、原因和整改建议，并用于生成批注。",
    "checkLevel": "NORMAL"
  }'
```
