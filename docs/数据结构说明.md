# 数据结构说明

## 1. 模型选择

前端只提交模型厂商和型号：

```json
{
  "provider": "deepseek",
  "model": "deepseek-chat"
}
```

支持的 `provider`：

```json
["deepseek", "chatgpt", "claudecode", "kimi", "glm"]
```

API Key 和 Base URL 只在 Python 本地配置中维护，前端不传递这些敏感字段。

## 3. Java 启动 Python 请求对象

Java 使用 `ProcessBuilder` 启动 Python 脚本。请求参数写入本地 JSON 文件，再把该 JSON 文件路径作为 Python 参数传入。

```json
{
  "provider": "deepseek",
  "model": "deepseek-chat",
  "work_dir": "results/善意想",
  "checked_file": "results/善意想/待检测文件/单奕翔：变化中的永恒——论中国民间音乐的“循环”逻辑.docx",
  "standard_file": "results/善意想/规则规范文件/中央音乐学院格式规范pdf.pdf",
  "format_rule_output": "results/善意想/规则抽取结果/format_rule.json",
  "check_result_output": "results/善意想/检测结果/format_check_result.json",
  "analysis_output": "results/善意想/检测结果/format_check_analysis.docx",
  "annotated_output": "results/善意想/检测后带批注的源文件/单奕翔_格式检查批注版.docx"
}
```

    "file_name": "中央音乐学院格式规范pdf.pdf",
    "file_type": "pdf",

## 7. Issue 对象

```json
{
  "issue_id": "I001",
  "category": "font_and_size",
  "severity": "medium",
  "location": {
    "page": "1",
    "section": "摘要",
    "paragraph_index": "3",
    "object_type": "paragraph",
    "quote": "本文研究..."
  },
  "anchor_text": "本文研究...",
  "rule_id": "R010",
  "rule_name": "摘要字体",
  "expected": "宋体小四号",
  "actual": "黑体小四号",
  "problem": "摘要字体不符合规范。",
  "reason": "规范要求摘要使用宋体小四号。",
  "suggestion": "将摘要正文修改为宋体小四号。",
  "comment_text": "错误原因：摘要字体不符合规范。\n规范要求：宋体小四号。\n修改建议：将摘要正文修改为宋体小四号。",
  "confidence": "high",
  "need_manual_confirmation": false
}
```

批注文本固定格式：

```text
错误原因：{reason}
规范要求：{expected}
修改建议：{suggestion}
```
